# UI Specifications — Sheikhi App (4 Screens)

> Source of truth: generated by reading the live code. Nothing invented.
> Direction: RTL (Arabic only). Theme: light + dark.

---

## Screen 1: الأقسام العلمية

Two linked screens — the section grid, and the books-inside-a-section drilldown.

---

### 1A — قائمة الأقسام (`/sections`)

**Widget:** `SectionsPage`  
**Cubit:** `SectionsCubit` / `SectionsState`

#### AppBar

| Element | Detail |
|---|---|
| Title | "الأقسام العلمية", centered |
| Leading | Back button (auto) |
| Actions | None |

#### Body — Loaded State

`RefreshIndicator` → `GridView.builder`

- 2 columns, crossAxisSpacing=8, mainAxisSpacing=8, childAspectRatio=1.1
- Padding: 16px all sides

Each `SectionGridItem` (Card + InkWell):

```
┌─────────────────────┐
│                     │
│    [Icon  40px]     │  ← SectionIcons.fromKey(), color = primary
│   [Section Name]    │  ← titleSmall, bold, centered, max 2 lines
│     كتاب  N         │  ← bodySmall, onSurfaceVariant
│                     │
└─────────────────────┘
```

- Tap → `context.push('/sections/{id}?name={encodedName}')`

#### Screen States

| State | Shown |
|---|---|
| Initial / Loading | `CircularProgressIndicator` centered |
| Loaded | 2-column grid of section cards |
| Empty | `EmptyState`: icon=`category_outlined`, "لا توجد أقسام بعد" |
| Error | `ErrorState`: message + retry → `SectionsCubit.loadSections()` |

**Data:** `sections` table (all rows, ordered by `order_index`)

---

### 1B — كتب القسم (`/sections/:sectionId`)

**Widget:** `SectionBooksPage` (StatefulWidget)  
**Cubit:** `SectionBooksCubit` / `SectionBooksState`

#### AppBar

| Element | Detail |
|---|---|
| Title | Section name (query param) or "كتب القسم" if empty, centered |
| Leading | Back button (auto) |
| Actions | None |

#### Body — Loaded State

`RefreshIndicator` → `Column`:

**1 — Search field** (always visible, pinned above list)

- `TextField`, hintText="بحث في الكتب...", prefixIcon=`Icons.search`
- Padding: 16px all sides
- Client-side filter on `book.title.contains(query)` — no extra Supabase call

**2 — `ListView.separated`** (or inline `EmptyState` if filtered result is empty)

Each `_BookListItem` (Card + InkWell):

```
┌──────────────────────────────────────────────┐
│ [Cover]  [Title bold, max 2 lines]      [›]  │
│ 56×76px  [Description, max 2 lines]          │
│          ── if enrolled & has lessons ──      │
│          [Progress bar]                      │
│          [N%  •  completed/total درس]         │
│          ── if not enrolled ────────────      │
│          [📖 N درس]  or  [ابدأ التعلّم]      │
└──────────────────────────────────────────────┘
```

- Cover: `CachedNetworkImage` 56×76px, rounded 8px → letter placeholder on error
- Chevron `Icons.chevron_left` trailing (correct in RTL)
- Tap → `context.push('/books/{book.id}')`
- Empty search result: `EmptyState` icon=`search_off`, message='لا توجد نتائج لـ "$query"'

#### Screen States

| State | Shown |
|---|---|
| Initial / Loading | `CircularProgressIndicator` centered |
| Loaded | Search field + book list |
| Empty | `EmptyState`: icon=`menu_book_outlined`, "لا توجد كتب في هذا القسم بعد" |
| Error | `ErrorState`: message + retry |

**Data:** `books` table filtered by `section_id` + `lesson_progress` for enrolled progress

## Screen 2: إنجازاتي (`/achievements`)

**Widget:** `AchievementsPage` (StatefulWidget)  
**Cubit:** `AchievementsCubit` / `AchievementsState`  
**Also reads:** `AuthCubit` (student name for PDF certificate generation)

#### AppBar

| Element | Detail |
|---|---|
| Title | "إنجازاتي" |
| Leading | `automaticallyImplyLeading: false` |
| Actions | None |

#### Body — Loaded State

`RefreshIndicator` → `ListView` (padding: 16px all sides)

---

**Section 1 — Stats Row**

3 × `StatCard` in a `Row`, each `Expanded`:

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  ✓ circle   │  │  🏆 circle  │  │  🕐 circle  │
│      N      │  │      N      │  │      N      │
│ درس مكتمل   │  │    شهادة    │  │  ساعة دراسة │
└─────────────┘  └─────────────┘  └─────────────┘
    primary         #D4A017 gold      secondary
```

Each `StatCard`:
- 48×48 circle container (icon color @ 12% alpha background)
- `headlineSmall` bold colored number
- `labelSmall` label (onSurface @ 60% alpha)

| Card | Icon | Value | Label | Color |
|---|---|---|---|---|
| 1 | `check_circle_outline` | `completedLessons` | درس مكتمل | `primary` |
| 2 | `emoji_events_outlined` | `certificateCount` | شهادة | `#D4A017` gold |
| 3 | `schedule_outlined` | `estimatedStudyHours` | ساعة دراسة | `secondary` |

> Estimated hours = `ceil((completedLessons × 15) / 60)`

---

**Section 2 — النشاط الدراسي**

- Title: "النشاط الدراسي", `titleMedium` bold
- If `activityByDate` not empty → `HeatMapCalendar` (flutter_heatmap_calendar)
  - 4 colour buckets: `primary` @ 25% / 50% / 75% / 100% alpha
  - Color tip: "أقل" (fontSize 10) left · "أكثر" (fontSize 10) right
  - Default cell color: `surfaceContainerHighest`, text color: `onSurface`
- If empty → centered text "ابدأ الدراسة لترى نشاطك هنا" (bodyMedium, onSurface @ 50% alpha)

Activity bucketing — event count per day → colour level:

| Events/day | Bucket |
|---|---|
| ≥ 8 | 4 (full opacity) |
| ≥ 5 | 3 |
| ≥ 3 | 2 |
| 1–2 | 1 (lightest) |

Events counted: completed lessons (`lesson_progress.updated_at`) + exam submissions (`final_exam_attempts.submitted_at`)

---

**Section 3 — شهاداتي**

- Title: "شهاداتي", `titleMedium` bold
- If no certs → `EmptyState`: icon=`emoji_events_outlined`, "لا توجد شهادات بعد\nأكمل اختباراً شاملاً للحصول على شهادة"
- If has certs → `ListView.separated` (shrinkWrap + NeverScrollableScrollPhysics inside parent)
  - Each item: `CertificateCard` widget (`features/certificates/widgets/`)
  - Download button action:
    1. `CertificatePdfGenerator.generate(cert, studentName, bookTitle, sheikhName)`
    2. `Printing.sharePdf(bytes, filename: 'شهادة.pdf')` → native share sheet
    3. On error → SnackBar red: "حدث خطأ أثناء توليد الشهادة"

#### Screen States

| State | Shown |
|---|---|
| Initial / Loading | `CircularProgressIndicator` centered |
| Loaded | Stats row + Heatmap + Certificates (empty certs handled inline) |
| Error | `ErrorState`: message + retry → `AchievementsCubit.loadAchievements()` |
| Empty | No dedicated state — handled inline inside Loaded |

**Data sources:**

| Table | Fields used |
|---|---|
| `lesson_progress` | `completed=true` rows → count + `updated_at` for heatmap |
| `certificates` | count + full list ordered by `issued_at` DESC (limit 50) |
| `final_exam_attempts` | `submitted_at` for heatmap (limit 200) |

## Screen 3: الإشعارات (`/notifications`)

**Widget:** `NotificationsPage` (StatefulWidget)  
**Cubit:** `NotificationsCubit` / `NotificationsState`  
**Realtime:** Yes — Supabase channel subscription active while cubit is alive

#### AppBar

| Element | Detail |
|---|---|
| Title | "الإشعارات" |
| Leading | Back button (auto — pushed from Home) |
| Actions | `TextButton` "تحديد الكل كمقروء" — **visible only when `unreadCount > 0`** · tap → `NotificationsCubit.markAllRead()` |

#### Body — Loaded State

`RefreshIndicator` → `ListView.separated` (padding: 16px all sides, separator height: 8px)

Each `_NotificationCard` (AnimatedContainer 200ms + InkWell, borderRadius 12px):

```
┌──────────────────────────────────────────────────────┐
│  [Icon  ]   [Title — bold if unread]        [● dot] │
│  40×40px    [Body text, max 3 lines]                 │
│  circle bg  [Timestamp relative]                     │
└──────────────────────────────────────────────────────┘
```

**Type → icon mapping:**

| `type` value | Icon | Color |
|---|---|---|
| `live_stream` | `live_tv_outlined` | Red |
| `new_lesson` | `play_circle_outline` | `primary` |
| `reminder` | `alarm_outlined` | Orange |
| `achievement` | `emoji_events_outlined` | `#D4A017` gold |
| _(any other)_ | `notifications_outlined` | `primary` |

Icon container: 40×40px circle, icon color @ 12% alpha background.

**Unread card:**
- Background: `primaryContainer` @ 25% alpha
- Border: `primary` @ 30% alpha
- Title: bold weight
- Top-end corner: 8×8px `primary` filled circle dot

**Read card:**
- Background: `surface`
- Border: `outlineVariant`
- Title: normal weight
- No dot

**Timestamp format:**

| Elapsed | Format |
|---|---|
| < 60 min | منذ N دقيقة |
| < 24 hr | منذ N ساعة |
| < 7 days | منذ N يوم |
| ≥ 7 days | DD/MM/YYYY |

**On tap behavior:**
1. Calls `NotificationsCubit.markRead(notif.id)` immediately
2. `linkUrl` starts with `/` → `context.push(link)` (internal deep link)
3. `linkUrl` is http/https → `launchUrl` external browser
4. `linkUrl` null or empty → no navigation

#### Screen States

| State | Shown |
|---|---|
| Initial / Loading | `CircularProgressIndicator` centered |
| Loaded | Scrollable list of notification cards |
| Empty | `EmptyState`: icon=`notifications_none`, "لا توجد إشعارات بعد" |
| Error | `ErrorState`: message + retry → `NotificationsCubit.loadNotifications()` |

**Data sources:** `notifications` + `notification_reads` tables. Realtime subscription keeps list live without pull-to-refresh.

## Screen 4: حسابي / الإعدادات (`/profile`)

**Widget:** `ProfilePage` (StatefulWidget)  
**Cubits:** `ProfileCubit` / `ProfileState` · `ThemeCubit` / `ThemeMode` · `AuthCubit`

#### AppBar

| Element | Detail |
|---|---|
| Title | "حسابي" |
| Leading | `automaticallyImplyLeading: false` |
| Actions | None |

#### Body — Loaded State

`RefreshIndicator` → `ListView` (padding: 16px all sides)

---

**Section 1 — User Header** (centered column, 16px top padding)

```
        [InitialsAvatar  radius=40]
         [Full Name — titleLarge bold]
         [email — bodyMedium, onSurface @60%]
```

`InitialsAvatar`: circle with initials extracted from `full_name`.

---

**Section 2 — Stats Row**

3 × `_StatChip` in a `Row`, each `Expanded`:

```
┌────────────┐  ┌────────────┐  ┌────────────┐
│  📖 circle │  │  ✓ circle  │  │  🏆 circle │
│     N      │  │     N      │  │     N      │
│ كتاب مسجّل │  │ درس مكتمل  │  │   شهادة   │
└────────────┘  └────────────┘  └────────────┘
    primary        #D4A017          secondary
```

| Chip | Icon | Value | Label | Color |
|---|---|---|---|---|
| 1 | `menu_book_outlined` | `enrolledBooks` | كتاب مسجّل | `primary` |
| 2 | `check_circle_outline` | `completedLessons` | درس مكتمل | `#D4A017` gold |
| 3 | `emoji_events_outlined` | `certificates` | شهادة | `secondary` |

Same internal layout as `StatCard` in إنجازاتي: 48×48 circle icon · `headlineSmall` bold colored number · `labelSmall` label.

---

**Section 3 — Menu Card**

Single `Card` containing a `Column` of `ListTile`s separated by `Divider(height: 1, indent: AppSpacing.xl)`.

| # | Icon | Label | Trailing | Action |
|---|---|---|---|---|
| 1 | `emoji_events_outlined` | شهاداتي | chevron › | `context.push('/achievements')` |
| 2 | `question_answer_outlined` | أسئلتي | chevron › | `context.push('/my-questions')` |
| 3 | `lock_outline` | تغيير كلمة المرور | chevron › | `context.push('/profile/edit-password')` |
| 4 | `dark_mode` / `light_mode` | الوضع الليلي | `Switch` | `ThemeCubit.toggle()` |
| 5 | `info_outline` | عن التطبيق | chevron › | `showAboutDialog(name: AppConfig.sheikhName, version: '1.0.0')` |
| 6 | `logout` | تسجيل الخروج | chevron › | Confirmation dialog → `AuthCubit.signOut()` |

- Items 1–3, 5, 6: `_MenuItem` — leading icon, title, trailing `Icons.arrow_forward_ios` size 14 @ 50% alpha
- Item 4 (`_DarkModeMenuItem`): `BlocBuilder<ThemeCubit>`, trailing is `Switch` (no chevron), icon flips dark_mode ↔ light_mode
- Item 6: icon + label + chevron all use `colorScheme.error` (red)

**Sign-out `AlertDialog`:**

| Element | Value |
|---|---|
| Title | "تسجيل الخروج" |
| Body | "هل أنت متأكد أنك تريد تسجيل الخروج؟" |
| Cancel button | "إلغاء" — dismisses dialog |
| Confirm button | "تسجيل الخروج" — error color — calls `AuthCubit.signOut()` |

#### Screen States

| State | Shown |
|---|---|
| Initial / Loading | `CircularProgressIndicator` centered |
| Loaded | Avatar + Stats row + Menu card |
| Error | `ErrorState`: message + retry → `ProfileCubit.loadProfile()` |
| `ProfileUpdating` | Subclass of `ProfileLoaded` — same UI, mutation in flight |

**Data sources:**

| Table | Fields used |
|---|---|
| `users` | `full_name`, `email` |
| `enrollments` | row count per user |
| `lesson_progress` | `completed=true` row count |
| `certificates` | row count |
| `SharedPreferences` key `app_theme` | theme mode (via `ThemeCubit`) |
